Chapter 1 · The Language of Algebra

Algebra uses letters for numbers we do not know yet. Before solving anything, get the vocabulary right — every later chapter uses these words.

1.1 Building Blocks

WordMeaningExample
VariableA letter that stands for an unknown or changing valuex, y, a, n
ConstantA fixed number7, −3, ½
TermA number, a variable, or their product, separated from other terms by + or −5x², −3xy, 8
CoefficientThe number multiplying the variable part, with its signIn −4x² it is −4
Like termsSame variables raised to the same powers — only these can be added3x²y and −7x²y
Unlike termsDifferent variables or different powers3x² and 3x
ExpressionTerms joined by + / − (no “=” sign)2x + 3y − 5
EquationTwo expressions with “=”, true only for some values2x + 3 = 11 (only x = 4)

1.3 Sign Rules and Brackets

(+) × (+) = +(−) × (−) = +(+) × (−) = −(−) × (+) = −
RuleExample
A + before a bracket: drop the bracket, signs stay+(a − b) = a − b

1.4 Worked Examples

Example 1. Simplify 5x − 2(3x − 4) + 7.
= 5x − 6x + 8 + 7
→ −x + 15
Logic: −2 multiplies both terms inside, so −4 becomes +8. Then combine like terms: 5x − 6x = −x and 8 + 7 = 15.
Example 2. Multiply (2x + 3)(x − 4).
= 2x·x − 2x·4 + 3·x − 3·4 = 2x² − 8x + 3x − 12
→ 2x² − 5x − 12
Logic: Each of the 2 terms in the first bracket meets each of the 2 terms in the second — 4 products in total.
Example 3. Find the value of 2a² − 3ab + b² when a = 2, b = −3.
= 2(4) − 3(2)(−3) + 9 = 8 + 18 + 9
→ 35
Logic: Always put a negative value inside brackets before squaring or multiplying: (−3)² = 9, and −3 × 2 × (−3) = +18.

1.5 Common Mistakes to Avoid

  • 3x + 2y cannot be written as 5xy. Only like terms combine.
  • −(x − 3) is −x + 3, not −x − 3. Flip every sign in the bracket.
  • −x² at x = −2 is −4, because only x is squared. But (−x)² = 4.
  • (x + 3)² is not x² + 9. The middle term 6x is missing — see Chapter 3.

Chapter 2 · Laws of Exponents

In aⁿ, a is the base and n is the exponent (power). These nine laws handle every power question at the foundation level. They work only when the base is the same.

2.1 The Nine Laws

#LawRuleExample
1Product (same base)aᵐ × aⁿ = aᵐ⁺ⁿ2³ × 2⁴ = 2⁷ = 128
2Quotient (same base)aᵐ ÷ aⁿ = aᵐ⁻ⁿ5⁶ ÷ 5⁴ = 5² = 25
3Power of a power(aᵐ)ⁿ = aᵐⁿ(3²)³ = 3⁶ = 729
4Power of a product(ab)ⁿ = aⁿbⁿ(2x)³ = 8x³
5Power of a quotient(a/b)ⁿ = aⁿ/bⁿ(2/3)² = 4/9
6Zero exponenta⁰ = 1 (a ≠ 0)7⁰ = 1, (−5)⁰ = 1
7Negative exponenta⁻ⁿ = 1/aⁿ2⁻³ = 1/8, (2/3)⁻² = 9/4
8Root as a powera^(1/n) = ⁿ√a27^(1/3) = 3
9Fractional powera^(m/n) = (ⁿ√a)ᵐ8^(2/3) = 2² = 4
Same base, same power: if aᵐ = aⁿ (a ≠ 0, 1, −1) then m = n. To solve an exponent equation, write both sides with the same base and compare powers.

2.2 Bases Worth Spotting

2.3 Worked Examples

Example 1. Solve 8ˣ = 32.
(2³)ˣ = 2⁵ ⇒ 2³ˣ = 2⁵ ⇒ 3x = 5
→ x = 5/3
Logic: 8 and 32 are both powers of 2. Make the bases equal, then compare powers.
Example 2. Simplify (16)^(3/4) × (125)^(−1/3).
= (2⁴)^(3/4) × (5³)^(−1/3) = 2³ × 5⁻¹ = 8 × 1/5
→ 8/5
Logic: Break each number into its prime base first, then multiply the powers (Law 3).
Example 3. Which is greater: 2⁴⁰ or 3²⁵?
2⁴⁰ = (2⁸)⁵ = 256⁵ and 3²⁵ = (3⁵)⁵ = 243⁵
→ 2⁴⁰ is greater
Logic: Make the powers equal (both ⁵ here, using the HCF of 40 and 25), then compare the bases.

2.4 Common Mistakes to Avoid

  • 2³ × 3² cannot be combined — the bases differ. Calculate: 8 × 9 = 72.
  • (a + b)² ≠ a² + b². Law 4 works for products, not sums.
  • 2⁻³ is 1/8, a positive number — a negative power does not make the answer negative.
  • (2³)² = 2⁶ = 64, but 2^(3²) = 2⁹ = 512. Brackets matter.

Chapter 3 · Algebraic Identities & Factorisation

Identities are ready-made expansions. Learn them in both directions: left → right to expand, right → left to factorise.

3.2 Know the Sum and Product, Know Everything

Many questions give you a + b (or a − b) and ab, then ask for something else. Do not find a and b — use these rearranged identities.

To findUse

3.3 Four Ways to Factorise

Factorising means writing an expression as a product. Try the methods in this order.

  1. Take out the common factor. 6x² + 9x = 3x(2x + 3)
  2. Group in pairs. ax + ay + bx + by = a(x + y) + b(x + y) = (a + b)(x + y)
  3. Match an identity. 9x² − 25 = (3x)² − 5² = (3x + 5)(3x − 5)
  4. Split the middle term (for ax² + bx + c). Find two numbers whose product is a × c and sum is b, split bx into those two parts, then group.

3.4 Worked Examples

Example 1. Factorise x² + 5x − 24.
Need product −24, sum +5 → +8 and −3
x² + 8x − 3x − 24 = x(x + 8) − 3(x + 8)
→ (x + 8)(x − 3)
Logic: A negative product means the two numbers have opposite signs; the bigger one takes the sign of the middle term.
Example 2. Factorise 3x² − 11x + 6.
a × c = 18; need product 18, sum −11 → −9 and −2
3x² − 9x − 2x + 6 = 3x(x − 3) − 2(x − 3)
→ (3x − 2)(x − 3)
Logic: Positive product with negative sum means both numbers are negative.
Example 3. If a + b = 8 and ab = 15, find a² + b² and a³ + b³.
a² + b² = 8² − 2(15) = 64 − 30 = 34
a³ + b³ = 8³ − 3(15)(8) = 512 − 360 = 152
→ 34 and 152
Logic: Check with a = 3, b = 5: 9 + 25 = 34 and 27 + 125 = 152. ✔

Chapter 4 · Linear Equations

A linear equation has every variable to the power 1. One variable needs one equation; two variables need two independent equations.

4.1 The Balance Rule

An equation is a balance. Whatever you do to one side, do to the other. In practice this means a term that crosses the “=” sign changes to its opposite operation.

On one sideMoves across asExample
+ 5− 5x + 5 = 12 ⇒ x = 7
− 5+ 5x − 5 = 12 ⇒ x = 17
× 3÷ 33x = 12 ⇒ x = 4
÷ 3× 3x/3 = 12 ⇒ x = 36

4.2 Solving in One Variable

  1. Clear fractions: multiply both sides by the LCM of all denominators.
  2. Open every bracket.
  3. Bring all x-terms to one side and all numbers to the other.
  4. Combine, then divide by the coefficient of x.
  5. Check by putting the answer back into the original equation.
Example 1. Solve (x − 1)/3 + (x + 2)/4 = 4.
× 12: 4(x − 1) + 3(x + 2) = 48
4x − 4 + 3x + 6 = 48 ⇒ 7x = 46
→ x = 46/7
Logic: LCM of 3 and 4 is 12. Multiply every term, including the 4 on the right.

4.3 Two Variables: Two Methods

Substitution

Make one variable the subject of one equation (e.g. x = y + 3) and put it into the other. Best when a variable already has coefficient 1.

Elimination

Multiply the equations so that one variable has equal coefficients, then add or subtract to remove it. Best when no coefficient is 1.

Example 2. Solve 3x + 4y = 18 and 2x − 3y = −5.
(×3): 9x + 12y = 54
(×4): 8x − 12y = −20
Add: 17x = 34 ⇒ x = 2; then 6 + 4y = 18 ⇒ y = 3
→ x = 2, y = 3
Logic: The y-coefficients 4 and −3 become 12 and −12, so adding removes y.
Example 3 (the swap trick). Solve 47x + 31y = 63 and 31x + 47y = 15.
Add: 78(x + y) = 78 ⇒ x + y = 1
Subtract: 16(x − y) = 48 ⇒ x − y = 3
→ x = 2, y = −1
Logic: When the coefficients are swapped between the two equations, adding and subtracting gives x + y and x − y directly.

4.4 Answer Without Solving

Often the question asks for x + y, x − y or some combination like 4x + 7y — not x and y themselves. Then you do not need to find x and y. Combine the equations directly.

When you seeDo thisYou get
Coefficients swapped: ax + by and bx + ayAdd the equations(a + b)(x + y)
Coefficients swapped: ax + by and bx + aySubtract the equations(a − b)(x − y)

Example 4. If 7x + 5y = 41 and 5x + 7y = 31, find x + y and x − y.
Add: 12x + 12y = 72 ⇒ x + y = 6
Subtract: 2x − 2y = 10 ⇒ x − y = 5
→ x + y = 6, x − y = 5
Logic: Here x = 5.5 and y = 0.5 — messy decimals. Combining the equations avoids them entirely.
Example 5. If 2x + y = 10 and x + 3y = 15, find 4x + 7y.
m(2x + y) + n(x + 3y) = 4x + 7y ⇒ 2m + n = 4 and m + 3n = 7 ⇒ m = 1, n = 2
4x + 7y = 1(10) + 2(15)
→ 40
Logic: Match the x-coefficients and the y-coefficients to find the multipliers. Often you can spot them by eye: Eq 1 + 2 × Eq 2.
Example 6. If a + 2b + 3c = 20 and 3a + 2b + c = 12, find a + b + c.
Add: 4a + 4b + 4c = 32
→ a + b + c = 8
Logic: Three unknowns and only two equations — you cannot find a, b, c separately, but you can still find their sum.

4.5 How Many Solutions?

For a₁x + b₁y = c₁ and a₂x + b₂y = c₂, compare the ratios:

Chapter 5 · Quadratic Equations

A quadratic equation has the form ax² + bx + c = 0 with a ≠ 0. It has at most two roots (solutions).

5.1 Three Ways to Solve

MethodHowUse when
FactorisationSplit the middle term (3.3), set each bracket = 0Roots are neat numbers — try this first
Square rootx² = k ⇒ x = ±√kNo x-term (b = 0)
Formulax = [−b ± √(b² − 4ac)] / 2aFactors are not obvious; always works
Zero-product rule: if (x − p)(x − q) = 0 then x = p or x = q. This works only when the right side is 0. Also, never cancel x from both sides of x² = 5x — you lose the root x = 0.

5.2 The Discriminant D = b² − 4ac

Value of DNature of roots
D > 0Two different real roots (rational if D is a perfect square)
D = 0Two equal real roots, each = −b/2a
D < 0No real roots

5.3 Sum and Product of Roots

If α and β are the roots of ax² + bx + c = 0:

α + β = −b/aαβ = c/ax² − (α + β)x + αβ = 0

The third form builds a quadratic from its roots: x² − (sum)x + (product) = 0.

5.4 Worked Examples

Example 1. Solve 2x² + x − 6 = 0.
a × c = −12; need sum +1 → +4 and −3
2x² + 4x − 3x − 6 = 2x(x + 2) − 3(x + 2) = (2x − 3)(x + 2) = 0
→ x = 3/2 or x = −2
Logic: Set each factor to zero: 2x − 3 = 0 and x + 2 = 0.
Example 2. Solve x² − 6x + 4 = 0.
D = 36 − 16 = 20; x = (6 ± √20)/2 = (6 ± 2√5)/2
→ x = 3 ± √5
Logic: D = 20 is not a perfect square, so factorising will not work; use the formula.
Example 3. If α, β are roots of x² − 5x + 3 = 0, find α² + β².
α + β = 5, αβ = 3; α² + β² = (α + β)² − 2αβ = 25 − 6
→ 19
Logic: No need to find the roots. Sum and product plus the Chapter 3 identity give the answer.
